Project Overview

From circuit building to published research.

The project used hands-on Raspberry Pi activities to help students connect programming concepts with physical computing. Participants built circuits, controlled LEDs through GPIO pins, wrote Python scripts, and debugged both hardware and code.

I served as a lead student researcher and helped with the technical side of the activity, classroom implementation, troubleshooting, research documentation, and manuscript development.

Research Questions

How effective are interactive exercises in teaching Raspberry Pi GPIO basics and Python programming?

How do participating students perceive exercises led by student researchers?

What I Built & Taught

Technical learning activity

GPIO & Circuit Fundamentals

The activity introduced GPIO functionality using GPIO 17, simple LED circuits, resistors, and the relationship between high and low pin states.

Python Programming

Students used Python loops and delays to create a blinking LED, connecting basic programming logic to visible hardware behavior.

Troubleshooting

The exercise emphasized debugging loose connections, circuit mistakes, and code errors so students could practice problem solving in a physical-computing environment.

Student Support

Four student researchers supported the activity, helping participants work through setup, coding, and circuit issues while encouraging independent exploration.
